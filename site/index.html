Notiskin

Themes and plugins for the Notion desktop app on a Mac. Notiskin changes how Notion looks and works on your computer. It never changes your pages.

Making themesPickers or CSS, every variable, fonts, light and dark, and what the marketplace accepts. Making pluginsThe notiskin object, settings, developer mode, safety, review and publishing.

Using Notiskin

  1. Download Notiskin and drag it into Applications. Builds aren't signed yet, so macOS says the app is damaged. The README has the one command that fixes it.
  2. Open it, go to Settings and press Install into Notion. Give Notiskin permission in System Settings → Privacy & Security → App Management if macOS asks, then press the button again.
  3. Pick a theme in Themes. Browse has themes and plugins other people made.

If something goes wrong, Safe mode in Settings pauses every theme and plugin at once, and Settings → Diagnostics makes a report you can paste into a bug report with your Notion links and name hidden.

Making your own

  • A theme is a list of colors. Press New theme on the Themes page to make one with pickers and see it in Notion while you work. Read more.
  • A plugin is a JavaScript file. Turn on Settings → Developer to run plugins from a folder and have Notion reload when you save. Read more.

About

Notiskin is open source and MIT licensed, made in the open at github.com/notiskin/notiskin. Themes and plugins are shared through a marketplace that runs on Supabase, and sign-in is with GitHub. It works by starting Notion with a private debugging pipe and adding a style or a script to the page that is already open. It doesn't edit Notion's files.

Notiskin is open source (MIT). These pages live in the site/ folder of the repository, fixes are welcome.
